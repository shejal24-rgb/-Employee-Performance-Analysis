## 📌 Project Overview

This project focuses on analyzing employee performance data using Python.

The objective is to understand employee productivity, department-wise performance, salary distribution, job satisfaction and the relationship between work experience and performance.

## 🎯 Project Objectives

- Analyze employee performance across departments.
- Identify high-performing departments.
- Compare average salaries.
- Understand employee satisfaction levels.
- Analyze experience and performance relationships.
- Evaluate project completion trends.
- Discover meaningful HR insights.
